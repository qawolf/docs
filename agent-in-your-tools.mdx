The QA Wolf agent you work with inside QA Wolf also answers in Slack, Linear, and GitHub pull requests. In each tool you connect it once, then choose where it can answer.

| Tool | What to set up | Guide |
|---|---|---|
| Slack | Connect Slack, then add the agent to each channel. | [Slack](/Slack) |
| Linear | Connect Linear and choose which teams can use the agent. | [Linear](/Linear) |
| GitHub | Have your QA Wolf representative activate `@qawolf` comments, then give the QA Wolf GitHub App access to each repository. | [GitHub pull requests](/github-pull-requests) |
| Coding agents | Install the QA Wolf MCP in Claude Code, Codex, or another coding agent. | [QA Wolf MCP](/qawolf-mcp) |

## What you can ask the agent

The agent works from your QA Wolf workspace: its flows, runs, environments, and bug reports. From any of these tools you can ask it to:

- Explain why a run failed, or what changed since the last one.
- Check the status of your latest runs.
- Report a bug in your application.
- Create a flow, fix a failing one, or run flows.

Each guide has example requests for its tool.

Everything the agent changes, it changes in QA Wolf. It reads the thread, issue, or pull request you asked from, and the only thing it adds there is its replies. It never builds, runs, or edits your application's code.

## Who can ask

Anyone who can reach the agent in a connected tool can ask it for any of the above. They don't need a QA Wolf account.

- **Slack** — anyone in your Slack workspace, in a direct message or in a channel the agent is in.
- **Linear** — anyone with access to a Linear team the agent can use.
- **GitHub** — owners and members of the repository's organization, collaborators, and contributors with write access.

## If the agent doesn't answer

Each guide lists the reasons the agent stays quiet in that tool, and what each of its "can't help" replies means: [Slack](/Slack#if-the-agent-doesnt-answer), [Linear](/Linear#if-the-agent-doesnt-answer), and [GitHub pull requests](/github-pull-requests#if-the-agent-doesnt-answer).
