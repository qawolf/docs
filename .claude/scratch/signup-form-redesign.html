What changed this round

  • Copy: "You have access to a QA Wolf workspace" (a prerequisite check) → "Sign up to get started" (an actual call to action) — the sentence now asks for the action instead of describing a precondition.
  • Framing: moved out of the <Check> prerequisite callout entirely. A Check block says "verify this before you proceed" — wrong shape for something you do first. It's now step 1 of a <Steps> sequence, matching the site's own convention for genuine ordered procedures.
  • Form → link: dropped the embedded email-capture form entirely. Step 1 is now a plain link/button to app.qawolf.com/sign-up — simpler, and it sidesteps the two unresolved production blockers noted in the original snippet (CORS not configured for the docs domain, an unguarded window.qawAttribution dependency). The real signup flow already lives on that page; no reason to reimplement it in an iframe-less embed here.
  • Three steps now: Sign up → Install CLI → Automate your first test — a complete zero-to-first-test path in one guide.

They might belong next to the other setup guides currently on the Features tab (Workspace settings, Environment settings) rather than only inside this linear guide — worth deciding before step 2 gets real content.
