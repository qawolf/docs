`GET https://app.qawolf.com/api/v0/run-inputs-executables-signed-urls`

<Tip>
  If your build server supports `node`, use [`@qawolf/ci-sdk`](/libraries/ci-sdk/api-reference) instead of calling this endpoint directly.
</Tip>

This endpoint accepts app builds only: `.aab`, `.apk`, `.appimage`, `.deb`, `.ipa`, `.rpm`, and `.zip`. Any other extension returns a `400`. To upload a file your flows read, such as a `.csv` or `.pdf`, use [team storage](/use-files-in-flows#upload-a-file) instead.

<Steps>
  <Step title="Generate a signed URL">
    ```bash
    curl "https://app.qawolf.com/api/v0/run-inputs-executables-signed-urls?file=$DESTINATION_FILE_PATH" \
      -H "Authorization: Bearer $QAWOLF_API_KEY"
    ```

    Returns a `signedUrl` for the next step, plus `fileLocation` and `playgroundFileLocation` — see below for the full parameter and response reference.
  </Step>
  <Step title="Upload the file">
    `PUT {signedUrl}`

    The previous request returns the signed URL. It is not a fixed `/api/` endpoint — it points directly to Google Cloud Storage.

    ```bash
    curl -X PUT \
      --header "Content-Type: application/octet-stream" \
      --data-binary @some_file.zip \
      $SIGNED_URL
    ```
  </Step>
</Steps>

## Query parameters

| Parameter | Description |
| --- | --- |
| `file` | Destination file path. At minimum the filename and extension. May include directories. |
| `workspaceId` | Workspace to upload to. Required with an organization or user API key. Ignored by a workspace API key, which already implies its workspace. See [which workspace a request acts on](/rest-overview#which-workspace-a-request-acts-on). |

## Response

```json
{
  "fileLocation": "$TEAM_ID/$DESTINATION_FILE_PATH",
  "playgroundFileLocation": "$DESTINATION_FILE_PATH",
  "signedUrl": "https://..."
}
```

| Field | Description |
| --- | --- |
| `fileLocation` | Full path including team ID. Use this to reference the file in run configurations. |
| `playgroundFileLocation` | Path without team ID. Use this to reference the file in the playground. |
| `signedUrl` | Pre-signed URL for uploading the file. Use in the next step. |

## Response codes

| Code | Description |
| --- | --- |
| `200` | Success. |
| `400` | `file` is missing, or its extension isn't one this endpoint accepts. Also returned when an organization or user API key omits `workspaceId`. |

Plus the [common response codes](/rest-overview#common-response-codes).
