## Three ways to submit a coverage request

- Open a coverage request in the platform <Badge color="green">Recommended</Badge>

- Send a message in Slack, Teams, or Discord
- Tag QA Wolf in Jira or Linear. 

## What to include

<Steps>
  <Step title="**Objective:** What you want to test">
    _Example: Verify the user registration process to ensure a user can register and receive a confirmation email._
  </Step>
  <Step title="**Preconditions:** Any setup before the test can run.">
    _Example: Access to a user with admin permissions._ 
  </Step>
  <Step title="**Steps:** Actions for the test to complete. ">
    _Example:_

    - _Navigate to the registration page._
    - _Fill out the registration form with valid data._
    - _Submit the form._
    - _Check for a confirmation message._
    - _Verify a confirmation email is sent with correct details._
    - _Confirm that the user is created in the database._
  </Step>
  <Step title="**Test data:** Data the test will need">
    _Example: A unique email address and user details for registration._
  </Step>
  <Step title="**Expected results:** What should happen when everything works">
    _Example:_

    - _The form submits successfully._
    - _A confirmation message appears._
    - _A confirmation email is received._
    - _The user record is correctly created in the database._
  </Step>
  <Step title="**Postconditions:** Specify any clean-up work needed after the test.">
    _Example: Delete the test user from the database._
  </Step>

</Steps>
