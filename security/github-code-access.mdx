---
title: "GitHub code access security"
description: "What QA Wolf reads during an investigation, what can remain afterward, and how QA Wolf uses your code."
---

The QA Wolf Code GitHub App has read-only access to source code in the repositories you select. QA Wolf's AI can read your application code to investigate a failed flow or to create and maintain flows.

## What happens to code after an investigation?

During an investigation, QA Wolf can read files from GitHub or use a working copy of your repository. Application code that becomes part of a saved flow draft or a published test can remain after the investigation ends.

You can [turn off GitHub code access](/github-code-access#turn-off-code-access) in your workspace settings. An investigation already in progress may still have access.

## Does QA Wolf use my code to improve its AI?

QA Wolf never uses your application code to train models, evaluate agents, or otherwise improve its AI agents. QA Wolf's model providers process requests under agreements that prohibit them from training their models on your data.

## Where can my security team find reports?

Share the [QA Wolf Trust Center](https://trust.qawolf.com/) with your security team. It lists QA Wolf's subprocessors and lets reviewers request the SOC 2 Type 2 report and the penetration test report.
