## What QA Wolf syncs

For each QA Wolf run, the integration can:

- Create a new test run in TestRail.
- Sync automated test results (passed, failed, skipped).
- Include run metadata (name, run/bug link).
- Mark the test run as completed after results are synced.

Results are synced after runs reach Completed status in QA Wolf.

## Limitations

- Only one TestRail project can be configured per QA Wolf workspace.
- Test runs are created at the run level, with no test plan–level updates.
- The _Skipped_ test status must exist in TestRail.

## Requirements

- Active TestRail account
- API access enabled, which requires a TestRail **Administrator**

## How to set up the integration

<Steps>
  <Step title="Set up TestRail">
    Define a TestRail project to receive QA Wolf runs, and configure the custom test status _Skipped_.
  </Step>

  <Step title="Configure QA Wolf">
    Provide your TestRail username or login email, API key or password, and target project (project ID or URL).
  </Step>

  <Step title="Verify the integration">
    Once QA Wolf enables the integration, run your automated tests. A new test run appears in your TestRail project with synced results and metadata, marked completed.

    If runs don't appear as expected, contact your QA Wolf representative.
  </Step>
</Steps>
