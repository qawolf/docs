Integrate QA Wolf with [TestRail](https://www.testrail.com/) to centralize automated test results and reporting. QA Wolf configures this integration. You set up TestRail and provide credentials, then verify results once QA Wolf enables it.

## What QA Wolf syncs

For each QA Wolf run, the integration can:

- Create a new test run in TestRail.
- Sync automated test results (passed, failed, skipped).
- Include run metadata (name, run/bug link).
- Mark the test run as completed after results are synced.

Results are synced after runs reach Completed status in QA Wolf.

## Limitations

- Only one TestRail project can be configured per QA Wolf workspace.
- Test runs are created at the run level, with no test plan–level updates.
- The _Skipped_ test status must exist in TestRail.

## Requirements

- Active TestRail account
- API access enabled, which requires a TestRail **Administrator**
- Target TestRail project to receive QA Wolf runs
- Custom test status _Skipped_ configured in TestRail

## What to send QA Wolf

- TestRail username or login email
- TestRail API key or password, depending on your account configuration
- Target TestRail project (project ID or URL)

## Verify the integration

<Steps>
  <Step title="Run your tests">
    Run your automated tests in QA Wolf.
  </Step>

  <Step title="Check TestRail">
    After the run completes, a new test run appears in your TestRail project with synced results and metadata, marked completed.
  </Step>
</Steps>

If runs don't appear as expected, contact your QA Wolf representative.
