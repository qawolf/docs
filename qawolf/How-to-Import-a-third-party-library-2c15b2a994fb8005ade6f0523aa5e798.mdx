## Importing the default version of a library

<Steps>
    <Step>
    From the **Flows** tab, choose the flow you'd like to add imports to.
    </Step>
    <Step>
    Toggle **Code Mode** on.
    </Step>
    <Step>
    Click the <Icon icon="chevrons-down" /> icon to the right of **NPM Dependencies** to expand that file.
    </Step>
    <Step>
    Add your import statement.
    <Frame>
    ![](/images/building-and-maintaining-flows/image-7.png)
    </Frame>
    </Step>
</Steps>

## Importing a specific version of a library

<Steps>
    <Step>
    From the **Flows** tab, choose the flow you'd like to add imports to.
    </Step>
    <Step>
    Toggle **Code Mode** on.
    </Step>
    <Step>
    Click the <Icon icon="chevrons-down" /> icon to the right of **NPM Dependencies** to expand that file.
    </Step>
    <Step>
    Add your import statement.

    <Frame>
    ![](/images/building-and-maintaining-flows/image-8.png)
    </Frame>
    </Step>
    <Step>
    Specify the package version by clicking the button at the right end of the `import` line in **NPM Dependencies**. This will open the version modal. Specify the package version after the “@” sign.

    <Frame>
    ![](/images/building-and-maintaining-flows/image-9.png)
    </Frame>
    </Step>
</Steps>
