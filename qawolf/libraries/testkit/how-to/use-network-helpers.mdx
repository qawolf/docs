# VPN Setup

Use the flow-facing VPN helper only after the runner has configured a client:

```ts
import { startOpenVpn } from "@qawolf/testkit";

const pid = await startOpenVpn({
  configPath: "/tmp/client.ovpn",
});
```

As the public option shapes settle, keep this page focused on practical usage
patterns and put exact option tables in the reference pages.
