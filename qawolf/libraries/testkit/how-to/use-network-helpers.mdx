# VPN Setup

Use network helpers when a flow must reach private infrastructure.

## Start OpenVPN

```ts
import { startOpenVpn } from "@qawolf/testkit";

const pid = await startOpenVpn({
  configPath: "/tmp/client.ovpn",
});

console.log(`OpenVPN started as ${pid}`);
```

`startOpenVpn(...)` is a top-level flow helper. It requires the runner to
configure the testkit client first.

## WireGuard Boundary

WireGuard exists on the runner-facing client ports today. It is not exported as
a top-level `startWireGuard(...)` helper.

```ts
import { createTestkitClient } from "@qawolf/testkit/client";

const client = createTestkitClient({
  startWireGuard: async ({ configPath }) => configPath,
});
```

Use this in runner or harness setup, not ordinary flow code.
