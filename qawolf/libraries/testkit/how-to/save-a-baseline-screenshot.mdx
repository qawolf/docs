# Baseline Screenshot

Use `saveBaselineScreenshot(...)` after the runner has configured a testkit
client with snapshot support.

```ts
import { saveBaselineScreenshot } from "@qawolf/testkit";

await saveBaselineScreenshot(page, "home-screen");
```

This recipe assumes the runner passed `saveSnapshot(...)` into
`createTestkitClient(...)`.

For the screenshotable type and error behavior, see the
[Core Reference](/qawolf/libraries/testkit/api-reference/core).
