# Read QR Code

Use the current web entry point to decode a QR code from a page element:

```ts
import { readQRCode } from "@qawolf/testkit/web";

const value = await readQRCode(page, ".qr-code");
```

## Current Behavior

The helper:

- screenshots the matching locator
- parses the PNG bytes
- returns the decoded QR code string if one is present
