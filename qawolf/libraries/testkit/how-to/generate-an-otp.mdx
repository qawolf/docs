# Generate An OTP

Use the top-level package when a flow needs to generate a one-time password from
an `otpauth://` URI.

```ts
import { otp } from "@qawolf/testkit";

const code = otp.fromUri(
  "otpauth://totp/QA%20Wolf:qa%40example.com?secret=JBSWY3DPEHPK3PXP&issuer=QA%20Wolf",
);
```

## Why This Helper Is Nice

- no runner wiring is required
- the flow does not need to construct an OTP client
- the output stays close to how OTP values are used in end-to-end flows
