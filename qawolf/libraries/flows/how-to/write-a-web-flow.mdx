# Write A Web Flow

Use `@qawolf/flows/web` when the flow runs in a web browser or Electron-style
environment.

The web package exposes:

- `flow(...)`
- `launch(...)`
- `expect`

The source code also exports web-specific types and launch result types through
the same entry point.

## Start With A Launch-Enabled Flow

```ts
import { flow } from "@qawolf/flows/web";

export default flow(
  "Open homepage",
  {
    target: "Web - Chrome",
    launch: true,
  },
  async ({ page }) => {
    await page.goto("https://example.com");
  },
);
```

This is the right starting point when the callback should receive:

- `page`
- `context`
- optionally `browser`

## Use The No-`launch` Path For Imperative Startup

If you pass the target directly, the callback does not receive `page`
automatically.

Use that path when you want to control startup imperatively:

```ts
import { flow, launch } from "@qawolf/flows/web";

export default flow("Open homepage", "Web - Chrome", async () => {
  const { page } = await launch();
  await page.goto("https://example.com");
});
```

## Use Declarative Launch When Startup Is Part Of The Flow

If the flow definition itself should request a launched browser session, pass an
object target with `launch`:

```ts
import { flow } from "@qawolf/flows/web";

export default flow(
  "Open homepage in Firefox",
  {
    target: "Web - Firefox",
    launch: true,
  },
  async ({ browser, context, page }) => {
    await page.goto("https://example.com");
  },
);
```

The web tests confirm that `launch: true` is supported as the default browser
launch shorthand and that the callback receives launched browser session
objects.

## Use `launch()` For More Explicit Control

Use `launch()` when the flow needs to decide launch behavior at runtime or when
you need a mode such as persistent browser context or Electron.

```ts
import { flow, launch } from "@qawolf/flows/web";

export default flow("Persistent profile", "Web - Chrome", async () => {
  const { page } = await launch({
    browserContext: "persistent",
    userDataDir: "/tmp/profile",
  });

  await page.goto("https://example.com");
});
```

On web:

- `launch({ browserContext: "persistent" })` maps to the underlying persistent
  context behavior
- GPU launch behavior is selected from the flow target
- `launch({ kind: "electron", executablePath })` routes through Electron launch
  support

See [Web Reference](/qawolf/libraries/flows/api-reference/web) for the launch shapes.

## Use `expect` Inside The Flow Runtime

`@qawolf/flows/web` exports `expect`, but the source marks it as a type-safe
stub that is replaced by the runner while the flow executes.

That means:

- use it inside flow execution
- do not treat the package-level export as a standalone assertion library
