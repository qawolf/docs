# Launch Electron

Use Electron launch mode when the target is a desktop app instead of a browser
page.

```ts
import { flow, launch } from "@qawolf/flows/web";

export default flow("Open desktop app", "Web - Chrome", async () => {
  const { electronApplication, firstWindowPage } = await launch({
    kind: "electron",
    executablePath: "/Applications/MyApp.app/Contents/MacOS/MyApp",
  });

  await firstWindowPage.getByRole("button", { name: "Sign in" }).click();

  await electronApplication.close();
});
```

## Use The First Window Page

Most Electron tests start with `firstWindowPage`.

```ts
await firstWindowPage.getByLabel("Email").fill("qa@example.com");
await firstWindowPage.getByRole("button", { name: "Continue" }).click();
```

## Pass Launch Arguments

Use `args` when the app needs flags at startup.

```ts
const { firstWindowPage } = await launch({
  kind: "electron",
  executablePath: "/Applications/MyApp.app/Contents/MacOS/MyApp",
  args: ["--test-mode"],
});
```
