# Launch Electron

Use Electron launch mode when the target is a desktop app instead of a browser
page.

```ts
import { flow } from "@qawolf/flows/web";

export default flow(
  "Open desktop app",
  {
    target: "Web - Chrome",
    launch: {
      kind: "electron",
      executablePath: "/Applications/MyApp.app/Contents/MacOS/MyApp",
    },
  },
  async ({ page }) => {
    await page.getByRole("button", { name: "Sign in" }).click();
  },
);
```

## Use The First Window

The Electron flow callback receives the first window as `page`.

```ts
await page.getByLabel("Email").fill("qa@example.com");
await page.getByRole("button", { name: "Continue" }).click();
```

## Pass Launch Arguments

Use `args` when the app needs flags at startup.

```ts
export default flow(
  "Open test-mode desktop app",
  {
    target: "Web - Chrome",
    launch: {
      kind: "electron",
      executablePath: "/Applications/MyApp.app/Contents/MacOS/MyApp",
      args: ["--test-mode"],
    },
  },
  async ({ page }) => {
    await page.getByRole("button", { name: "Sign in" }).click();
  },
);
```
