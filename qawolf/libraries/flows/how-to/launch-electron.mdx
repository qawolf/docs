# Launch Electron

Use Electron launch mode when the flow targets a desktop app instead of a
browser tab.

```ts
import { launch } from "@qawolf/flows/web";

const { firstWindowPage } = await launch({
  kind: "electron",
  executablePath: "/Applications/My App.app",
});
```

Keep this page focused on practical Electron patterns rather than on the full
launch option reference.
