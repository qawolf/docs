# Mobile App From Env

Use environment-based app resolution when the runtime supplies the app path
through a known input.

```ts
import { launch } from "@qawolf/flows/android";

const { driver } = await launch({
  app: { env: "RUN_INPUT_PATH" },
  appPackage: "com.example.android",
});
```

The same pattern can be documented for iOS once the stable launch inputs are
captured in the reference pages.
