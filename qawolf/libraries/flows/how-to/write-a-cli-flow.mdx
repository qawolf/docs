# Write A CLI Flow

Use `@qawolf/flows/cli` when the flow needs runner utilities but does not need a
browser, Android device, or iOS device.

```ts
import { flow } from "@qawolf/flows/cli";

export default flow("Check Node", "Basic", async ({ runCommand }) => {
  const result = await runCommand({
    binary: "node",
    args: ["--version"],
  });

  console.log(result);
});
```

## Use The `Basic` Target

CLI flows currently support one target.

<CodeGroup>

```ts String target
export default flow("CLI task", "Basic", async ({ workflowInputs }) => {
  console.log(workflowInputs);
});
```

```ts Object target
export default flow(
  "CLI task",
  { target: "Basic" },
  async ({ workflowInputs }) => {
    console.log(workflowInputs);
  },
);
```

</CodeGroup>

## Common Dependencies

The callback receives base runner dependencies such as:

- `runCommand`
- `getInbox`
- `getOTP`
- `mountCifsShare`
- `startOpenVpn`
- `startWireGuard`
- `workflowInputs`
- `setOutput`

Use CLI flows for setup, teardown, notifications, and other non-UI work.
