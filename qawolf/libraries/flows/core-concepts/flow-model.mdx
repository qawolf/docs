# Flow Model

A flow has three parts:

```ts
flow("Name shown in QA Wolf", target, async (runtime) => {
  // test steps
});
```

- **Name** appears in runs, bug reports, and logs.
- **Target** selects the browser, device, or CLI environment.
- **Callback** contains the workflow steps.

## The Recommended Shape

Use `{ target, launch: true }` when the flow should start the session before the
callback runs.

```ts
import { flow } from "@qawolf/flows/web";

export default flow(
  "Checkout",
  { target: "Web - Chrome", launch: true },
  async ({ page }) => {
    await page.goto("https://example.com/cart");
  },
);
```

The callback receives the launched object for that platform:

| Entry point             | Launch object                |
| ----------------------- | ---------------------------- |
| `@qawolf/flows/web`     | `page`, `context`, `browser` |
| `@qawolf/flows/android` | `driver`                     |
| `@qawolf/flows/ios`     | `driver`                     |

## The Manual Launch Shape

Pass the target directly when the callback should decide when or how startup
happens.

```ts
import { flow, launch } from "@qawolf/flows/web";

export default flow("Checkout", "Web - Chrome", async () => {
  const { page } = await launch({
    browserContext: "persistent",
    userDataDir: "/tmp/qawolf-profile",
  });

  await page.goto("https://example.com/cart");
});
```

Use manual launch for:

- persistent browser profiles
- Electron apps
- mobile app paths chosen at runtime
- conditional startup branches

## CLI Flows Are Simpler

CLI flows do not launch a browser or mobile app.

```ts
import { flow } from "@qawolf/flows/cli";
import { readFile } from "node:fs/promises";

export default flow("Read build metadata", "Basic", async () => {
  const metadata = await readFile("build-metadata.json", "utf8");

  console.log(JSON.parse(metadata));
});
```

## `device` Is Not Startup

`device` is for broader mobile control after the flow is running.

```ts
import { device, flow } from "@qawolf/flows/android";

export default flow(
  "Location-aware screen",
  { target: "Android - Pixel", launch: true },
  async ({ driver }) => {
    await device.setGeoLocation({ latitude: 37.7749, longitude: -122.4194 });
    await driver.pause(1000);
  },
);
```

Reach for `device` when the test needs emulator or simulator behavior, not just
normal app startup.
