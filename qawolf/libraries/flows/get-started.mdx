# Get Started

`@qawolf/flows` is the wrapper around QA Wolf test code. It tells the runner
what to run, where to run it, and which runtime objects to inject.

Most users should start with a launch-enabled flow.

```ts
import { expect, flow } from "@qawolf/flows/web";

export default flow(
  "Sign in",
  { target: "Web - Chrome", launch: true },
  async ({ page }) => {
    await page.goto("https://example.com/login");
    await page.getByLabel("Email").fill("qa@example.com");
    await page.getByRole("button", { name: "Continue" }).click();

    await expect(page.getByText("Check your email")).toBeVisible();
  },
);
```

## Pick The Entry Point

Import from the package that matches the target you are authoring for.

<CodeGroup>

```ts Web
import { expect, flow } from "@qawolf/flows/web";
```

```ts Android
import { expect, flow } from "@qawolf/flows/android";
```

```ts iOS
import { flow } from "@qawolf/flows/ios";
```

```ts CLI
import { flow } from "@qawolf/flows/cli";
```

</CodeGroup>

Use the top-level package only for shared runtime helpers:

```ts
import { platform } from "@qawolf/flows";

if (platform.target === "Web - Chrome") {
  // Target-specific branch.
}
```

## Start With `launch: true`

`launch: true` asks QA Wolf to start the browser or mobile app before your
callback runs.

<CodeGroup>

```ts Web
export default flow(
  "Open dashboard",
  { target: "Web - Chrome", launch: true },
  async ({ page }) => {
    await page.goto("https://example.com/dashboard");
  },
);
```

```ts Android
export default flow(
  "Open Android app",
  { target: "Android - Pixel", launch: true },
  async ({ driver }) => {
    await driver.pause(1000);
  },
);
```

```ts iOS
export default flow(
  "Open iOS app",
  { target: "iOS - iPhone 15 (iOS 26)", launch: true },
  async ({ driver }) => {
    await driver.pause(1000);
  },
);
```

</CodeGroup>

Use this shape when the callback should receive launched runtime objects:

| Platform | Callback receives                          |
| -------- | ------------------------------------------ |
| Web      | `page`, `context`, and sometimes `browser` |
| Android  | `driver`                                   |
| iOS      | `driver`                                   |
| CLI      | base runtime dependencies only             |

## Launch Manually When Startup Is Conditional

Pass the target directly when the flow should decide how to launch inside the
callback.

```ts
import { flow, launch } from "@qawolf/flows/web";

export default flow("Open tenant", "Web - Chrome", async () => {
  const host = process.env["TENANT_HOST"] ?? "example.com";
  const { page } = await launch();

  await page.goto(`https://${host}/dashboard`);
});
```

This is useful for persistent browser profiles, Electron, app paths from
environment variables, and other startup choices that belong in the test logic.
