# Send A Message

The inbox handle includes `sendMessage(...)`:

```ts
const { sendMessage } = await mail.inbox({ new: true });

await sendMessage({
  subject: "Hello",
  text: "It works",
  to: "test@example.com",
});
```

## HTML Example

```ts
await sendMessage({
  subject: "Hello",
  html: "<b>It works</b>",
  to: "test@example.com",
});
```
