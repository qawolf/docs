# Unique Addresses

Use `new: true` when a test should not share an inbox with previous or parallel
runs:

```ts
const { emailAddress } = await mail.inbox({ new: true });
```

If the product under test does not accept `+` addressing, pass a custom
delimiter:

```ts
const { emailAddress } = await mail.inbox({ new: true, delimiter: "-" });
```
