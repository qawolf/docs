## 2\. Notify preview deployments

### 2.1 GitHub Action

Configure [<Icon icon="github"/> GitHubNotify QA Wolf on Deploy - GitHub Marketplace](https://github.com/marketplace/actions/notify-qa-wolf-on-deploy) to inform us when new preview environment deployments are released and are ready to be tested.

### 2.2 SDK

When GHAs are not an option, the

@qawolf/ci-sdk

npm package offers a flexible alternative. See the relevant documentation in the [NPM package](https://www.npmjs.com/package/@qawolf/ci-sdk).
