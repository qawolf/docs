QA Wolf helps teams plan, create, run, and maintain end-to-end tests automatically as part of the AI-driven software development lifecycle.

Using AI, QA Wolf maps your application, generates tests from natural-language prompts, and runs them in parallel on managed infrastructure. The tests are written as standard Playwright and Appium code and live in your GitHub repository, so your team keeps full ownership and can review, modify, and version them like any other code.

QA Wolf supports the full lifecycle of end-to-end testing—from identifying the user journeys that matter, to generating automation, to continuously validating releases as your product evolves.

Tests are organized within shared workspaces, where teams collaborate across environments and flows to validate critical user journeys. Runs can be triggered on demand, scheduled, or integrated into CI pipelines so teams always know whether their application is working as expected.

---

## How QA Wolf works

Testing with QA Wolf happens in three steps.

### Map

AI explores your application and identifies the user paths that can be tested. This creates a structured view of your product so teams can understand what to cover first.

### Automate

Describe a flow in plain language and QA Wolf generates Playwright and Appium tests that validate the behavior of your application. The resulting tests are standard code that your team owns and can modify.

### Run

Tests run in parallel across QA Wolf infrastructure. Runs can be triggered on demand, scheduled, or executed automatically from CI pipelines.

## Why use QA Wolf

QA Wolf helps teams build reliable end-to-end coverage without managing testing infrastructure or maintaining fragile automation.

### AI-generated automation

Describe user journeys in natural language, and QA Wolf generates test in Playwright and, coming soon, Appium.

### Customer-owned test code

Tests live in your GitHub repository and remain fully accessible to your team.

### Parallel execution by default

### Continuous validation

Tests run automatically across environments, so teams know when changes break critical user journeys.

### Clear coverage of critical paths

AI mapping helps teams understand what parts of the product are tested and where additional coverage may be needed.

## What you can test with QA Wolf

QA Wolf is designed to validate the workflows that matter most in modern applications—from simple journeys to complex multi-system interactions.

### Web applications

Automate critical paths across modern web applications.

Examples include:

- User registration and authentication
- Checkout and payment flows
- Onboarding experiences
- Account management
- Cross-browser behavior
- Accessibility
- Performance

### Native mobile applications

Test native mobile apps using Appium across Android emulators and real iOS devices.

QA Wolf supports:

- Gestures, layouts, and device orientation
- Push notifications and deep links
- camera, photos, and video interactions
- system permissions and prompts
- sensors such as GPS, Bluetooth, and Wi-Fi

### Multi-user workflows

Some systems require coordination between multiple users.

QA Wolf supports flows where separate users interact with the same system, such as:

- Marketplace buyer and seller interactions
- Approval workflows
- Collaborative product features
- Messaging and communication flows

### Cross-device journeys

Real user workflows often move across devices.

QA Wolf can automate scenarios such as:

- Starting a flow on desktop and finishing on mobile
- Email verification or push notification handoffs
- Journeys that move between web, iOS, and Android

### Desktop and extension environments

QA Wolf can automate applications beyond the browser, including:

- Electron applications
- Browser extensions and plugins
- Hybrid desktop applications built with web technologies

### Hardware and IoT integrations

QA Wolf can validate workflows that interact with connected systems and devices, including:

- Device pairing and provisioning
- Companion mobile app experiences
- Hardware-triggered backend events
