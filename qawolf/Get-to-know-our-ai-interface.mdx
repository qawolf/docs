## Overview: What the AI agent can do

QA Wolf AI helps you manage flows and edit code simply by chatting with the agent. You can ask questions, take actions, and review past activity without leaving the page.

You can ask the AI to create or update flows, adjust code in the editor, import packages, or explain part of your test. When possible, it applies your requested changes directly.

## How to interact with the agent

### Navigate to the agent chat

<Steps>
  <Step>
    Navigate to the Flows tab. The agent chat is in the right-side panel.

    <Frame>
      ![Screenshot of the Flows tab](/images/image-54.png)
    </Frame>
  </Step>
</Steps>

### Chat with the agent

<Steps>
  <Step>
    Type your request, then press enter or click the <Icon icon="arrow-up" /> icon.
  </Step>
</Steps>

### Speak to the agent:

<Steps>
  <Step>
    Click the <Icon icon="microphone" /> icon. Note: you may need to grant microphone access to QA Wolf.
  </Step>
  <Step>
    Speak your request. The agent will listen for when you’re done talking.
  </Step>
  <Step>
    To stop the AI from dictating, click the <Icon icon="x" /> icon.

    <Frame>
      ![Screenshot of the agent chat](/images/image-55.png)
    </Frame>
  </Step>
</Steps>

## How to: Use the agent controls

### Clear the chat history

<Steps>
  <Step>
    Click the <Icon icon="plus" /> icon to clear the AI’s latest response and start a new chat.

    <Frame>
      ![Screenshot of the agent chat](/images/image-56.png)
    </Frame>
  </Step>
</Steps>

### Get suggested prompts

<Steps>
  <Step>
    Click the <Icon icon="sparkles" /> icon to get contextualized prompt suggestions. These suggestions help you discover tasks the AI can perform and provide a starting point if you’re unsure how to phrase your request.

    <Frame>
      ![Screenshot of the agent chat](/images/image-57.png)
    </Frame>
  </Step>
</Steps>

### Open chat history

<Steps>
  <Step>
    Click the <Icon icon="clock-rotate-left" /> icon to open the history view and access previous AI conversations. You can reference earlier guidance, reuse prompts, or continue a session without re-entering context.

    <Frame>
      ![Screenshot of the agent chat](/images/image-58.png)
    </Frame>
  </Step>
</Steps>

### Show and hide the chat window

<Steps>
  <Step>
    Click the <Icon icon="chevrons-up" /> icon to expand the AI chat window.
  </Step>
  <Step>
    Click the <Icon icon="chevrons-down" /> icon to collapse the AI chat window.

    <Frame>
      ![Screenshot of the agent chat](/images/image-59.png)
    </Frame>
  </Step>
</Steps>
