## Overview: About environment variables

In the QA Wolf platform, environment variables are encrypted constants scoped to a specific environment.

You can use the same variable across environments by reusing the same name in each environment and setting the appropriate value for that environment (for example, BASE\_URL in Staging vs Production). QA Wolf doesn't enforce cross-environment consistency—this pattern relies on naming conventions.
