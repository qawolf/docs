## Overview: Dev Tools

### Logs tab

The **Logs** tab displays output from executed code, including errors and console log messages.

<Frame>
  ![](/images/building-and-maintaining-flows/image-30.png)
</Frame>

### Details tab

The **Details** tab provides a read-only summary of a completed test flow, including its overall result, timing, and detailed stage performance.

<Frame>
  ![](/images/building-and-maintaining-flows/image-31.png)
</Frame>

### Notes tab

The Notes tab allows users to leave context for others. Add a new note by hovering over the <Icon icon="pencil" /> icon, typing your note, and pressing Enter.

<Frame>
  ![](/images/building-and-maintaining-flows/image-32.png)
</Frame>

### Runs tab

The **Runs** tab shows the flow's attempt history.

## How to open dev tools

<Steps>
  <Step>
    From the Flows list on the **Flows** tab, choose a failing flow you want AI to fix
  </Step>
  <Step>
    Toggle **Code Mode** on.

    <Frame>
      ![](/images/building-and-maintaining-flows/image-33.png)
    </Frame>
  </Step>
  <Step>
    If the dev tools are closed, click **Open dev tools**. The dev tools appear below the editor window.

    <Frame>
      ![](/images/building-and-maintaining-flows/image-34.png)
    </Frame>
  </Step>
</Steps>
