### Create a group (if you don’t already have one)

<Steps>
  <Step>
    From the **Flows** tab, click the <Icon icon="folder-plus" /> icon next to the workspace name.
  </Step>
  <Step>
    Name the group and hit Enter.

    <Frame>
      ![](/images/building-and-maintaining-flows/image-21.png)
    </Frame>
    <Check>
      Use clear, descriptive names that reflect your app's feature areas—this helps both you and AI keep plans organized.
    </Check>
  </Step>
</Steps>

### Create a flow (if you don’t already have one)

<Steps>
  <Step>
    Hover over the group name and click the <Icon icon="plus" /> icon
  </Step>
  <Step>
    Name the flow in the text field that appears and hit Enter. You will see it in the group.

    <Frame>
      ![](/images/building-and-maintaining-flows/image-22.png)
    </Frame>
  </Step>
</Steps>

### Write Playwright or Appium code

<Steps>
  <Step>
    Toggle on **Code Mode** by clicking the <Icon icon="code" /> icon. You will see the code editor in the center panel.

    <Frame>
      ![](/images/building-and-maintaining-flows/image-23.png)
    </Frame>
  </Step>
  <Step>
    Click **Add test**.

    <Frame>
      ![](/images/building-and-maintaining-flows/image-24.png)
    </Frame>
    <Tip>
      Collapse and expand the Flows panel using the <Icon icon="arrows-left-right" /> icon to create more space for the editor.

      <Frame>
        ![](/images/building-and-maintaining-flows/image-25.png)
      </Frame>
    </Tip>
  </Step>
  <Step>
    Type the name of your new test and hit Enter. The newly created test will appear expanded in the code editor, prefilled with [AAA](https://www.qawolf.com/blog/intro-to-aaa) (Act-Arrange-Assert) comments.

    <Frame>
      ![](/images/building-and-maintaining-flows/image-26.png)
    </Frame>
    <Danger>
      As you type, QA Wolf automatically lints your code. If the linter detects errors, you won't be able to run or commit the test until those issues are resolved.

      <Frame>
        ![](/images/building-and-maintaining-flows/image-27.png)
      </Frame>
    </Danger>
  </Step>
</Steps>

### Publishing [changes](/qawolf/Check-in-changes-2c65b2a994fb8073826be9391a8e2238)

<Danger>
  You must review and publish your changes to save them.
</Danger>

<Steps>
  <Step>
    When ready to publish your test, click Review

    <Frame>
      ![](/images/building-and-maintaining-flows/image-28.png)
    </Frame>
  </Step>
  <Step>
    Review the changes in the side-by-side diff

    <Frame>
      ![](/images/building-and-maintaining-flows/image-29.png)
    </Frame>
  </Step>
  <Step>
    When you modify a flow’s code, you will see the history of all previous code versions on the left.
  </Step>
  <Step>
    When you're satisfied, enter a clear description of the change in the **Adding a comment** text field.
  </Step>
  <Step>
    Click **Publish changes** to confirm the update.
  </Step>
</Steps>
