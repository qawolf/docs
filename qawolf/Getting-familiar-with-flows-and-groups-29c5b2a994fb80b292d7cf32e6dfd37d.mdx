## Overview: Using groups and flows

Groups and flows organize your testing environment. Groups are the top-level feature areas (for example, *Authentication*, *Checkout*, or *Billing*). Flows break each group into specific user journeys or scenarios. Each flow contains the tests that run those steps.

Use [groups](/qawolf/Overview-Glossary-29c5b2a994fb806d93f2ce4554a2fcfc#group) to keep your environment easy to navigate—for both your team and the AI—so coverage planning and flow management stay organized.

Use [flows](/qawolf/Overview-Glossary-29c5b2a994fb806d93f2ce4554a2fcfc#flow) to plan how you'll test a feature before writing code. You can generate a starting plan with AI or create flows manually for more control.

The **Flows** tab is where you create and manage flows for the selected environment. By default, the list shows **All Flows**.

## How to create, edit & delete flows
<Check>
To add a flow, you must first [add a group](/qawolf/Overview-Get-familiar-with-flows-and-groups-29c5b2a994fb80b292d7cf32e6dfd37d).

### To create a new flow

<Steps>
<Step>
On the **Flows** tab, go to the **Flows** list.
</Step>

<Step>
Hover over the group where you want to add a flow.
</Step>

<Step>
Click the <Icon icon="plus" /> icon to the right of the group name.

<Frame>
![](/images/building-and-maintaining-flows/image-38.png)
</Frame>
</Step>

<Step>
Type the new flow’s name in the text field that appears.
</Step>

<Step>
Press **Enter** to add the flow to that group.
</Step>
</Steps>

<Check>
Use clear, descriptive names that reflect your app's feature areas—this helps both you and AI keep plans organized.
</Check>

## How to edit flow settings
### To access flow settings:

<Steps>
<Step>
Selecting a flow from the Flows list while in **No-code Mode**.

<Frame>
![](/images/building-and-maintaining-flows/image-50.png)
</Frame>
</Step>
</Steps>


### To add or remove tags from a flow:

<Steps>
<Step>
Hover over the tag names under Tags.
</Step>

<Step>
Click the <Icon icon="pencil" /> icon. This opens a drawer where you can also create new tags.
</Step>
</Steps>

### To set the Readiness status of a flow:

<Steps>
    <Step>
    Hover over the status under **Readiness**.
    </Step>

    <Step>
    Click the <Icon icon="pencil" /> icon.
    </Step>

    <Step>
    Select either Draft or Active status.
    </Step>
</Steps>

<Danger>
Only flows in Active status can be executed in scheduled runs.
</Danger>

### To move a flow to a different group:

<Steps>
    <Step>
    Hover over the group name under **Group**.
    </Step>

    <Step>
    Click the <Icon icon="pencil" /> icon.
    </Step>

    <Step>
    Select either group you want to move the flow to.
    </Step>
</Steps>

### To change the browser or device a flow uses to execute:

<Steps>
    <Step>
    Hover over the browser name under **Runs on**.
    </Step>

    <Step>
    Click the <Icon icon="pencil" /> icon. A modal appears.
    </Step>

    <Step>
    Select the App type and configure the relevant settings.

    <Frame>
    ![](/images/building-and-maintaining-flows/image-51.png)
    </Frame>
    </Step>
</Steps>
