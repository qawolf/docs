---
title: "How to integrate with Azure DevOps Boards"
---

<Check>
Go to [https://dev.azure.com/](https://dev.azure.com/) **ORGANIZATION_NAME**/\_settings/organizationPolicy — **ORGANIZATION_NAME** is your Azure DevOps Organization name.

**Because** QA Wolf connects to Azure DevOps using OAuth, you must enable **Third-party application access via OAuth**.

<Frame>
<img src="/images/integrate-your-issue-tracker/image-21.png"/>
</Frame>

If **Third-party application access via OAuth** is disabled, an Azure DevOps organization owner must enable it before QA Wolf can be authorized. If you are not an organization owner, contact your Azure DevOps administrator.
</Check>

<Steps>
<Step>
Select **Workspace settings** from the **Workspace name** dropdown above the flows list.

<Frame>
<img src="/images/integrate-your-issue-tracker/image-15.png"/>
</Frame>
</Step>
<Step>
Click **Integrations** from the left-side navigation bar.

<Frame>
<img src="/images/integrate-your-issue-tracker/image-16.png"/>
</Frame>
</Step>
<Step>
Click **Enable** next to Azure DevOps
</Step>
<Step>
Click on the connect button.

<Frame>
<img src="/images/integrate-your-issue-tracker/image-17.png"/>
</Frame>
</Step>
<Step>
Select **Azure DevOps** Service.

<Frame>
<img src="/images/integrate-your-issue-tracker/image-18.png"/>
</Frame>
</Step>
<Step>
Enter the Azure DevOps **Organization name** and click **Continue**.

<Frame>
<img src="/images/integrate-your-issue-tracker/image-19.png"/>
</Frame>
</Step>
<Step>
Click **Configuration**, then select the target project from the dropdown.

- Click **Disconnect at any time** to disable the integration.
    <Frame>
    <img src="/images/integrate-your-issue-tracker/image-20.png"/>
    </Frame>
</Step>
</Steps>
