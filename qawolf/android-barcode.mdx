The Android emulator's back camera supports virtual scene emulation. You can place a barcode or QR code image on the virtual table or wall, then trigger an animation that moves the camera toward it — simulating a real scan without a physical device.

This uses `device.setVirtualSceneImage()` and `device.playAutomation()` from `@qawolf/flows/android`. See the [Android Device Reference](/qawolf/libraries/flows/api-reference/android-device) for full API details.

## How it works

1. Store the barcode image in team storage
2. Place the image on the virtual scene (`table` or `wall`)
3. Play the `Walk_to_image_room` macro to animate the camera toward it
4. Wait for your app to detect and process the scan

## Example

```typescript
import { device, flow, launch } from "@qawolf/flows/android";

const barcodeImagePath = `${process.env.TEAM_STORAGE_DIR}/barcode.jpg`;

export default flow(
  "Scan barcode",
  { target: "Android - Pixel", launch: true },
  async ({ driver, test }) => {
    await test("set up virtual scene", async () => {
      await device.setVirtualSceneImage({
        image: barcodeImagePath,
        location: "table",
      });

      await device.playAutomation({
        macro: "Walk_to_image_room",
      });
    });

    await test("verify scan", async () => {
      // wait for your app to display the scanned value
      const barcodeText = await driver
        .$(`//android.widget.TextView[@resource-id='com.example.app:id/scanned_value']`)
        .waitForDisplayed({ timeout: 10_000 });

      const value = await driver
        .$(`//android.widget.TextView[@resource-id='com.example.app:id/scanned_value']`)
        .getAttribute("text");

      if (value !== "1234567890128") {
        throw new Error(`Unexpected scan value: ${value}`);
      }
    });
  },
);
```

<Note>
  The barcode image must encode the exact value your test expects. Store it in team storage and reference it via `process.env.TEAM_STORAGE_DIR`. See [Upload files](/qawolf/Uploading-manually) for instructions on adding files to team storage. If the scanned value doesn't match, verify the image in team storage encodes the correct barcode value.
</Note>

## Using `wall` instead of `table`

The virtual scene supports two placement locations. `table` places the image on a horizontal surface; `wall` places it on a vertical surface. Use whichever your app's scanning UI is optimized for.

```typescript
await device.setVirtualSceneImage({
  image: barcodeImagePath,
  location: "wall",
});
```

## Scanning mid-flow

If your test needs to scan a barcode after other interactions, call `setVirtualSceneImage` and `playAutomation` at the point in the flow where the scan should happen — not at the start.

```typescript
await test("navigate to scan screen", async () => {
  await driver.$(`//*[@text='Scan']`).click();
});

await test("scan barcode", async () => {
  await device.setVirtualSceneImage({
    image: barcodeImagePath,
    location: "table",
  });

  await device.playAutomation({
    macro: "Walk_to_image_room",
  });

  await driver
    .$(`//*[@text='Barcode Captured']`)
    .waitForDisplayed({ timeout: 10_000 });
});
```
