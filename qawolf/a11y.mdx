Use `axe-core` to scan a page for WCAG violations and fail the test if any are found. This is the foundation for all automated accessibility testing in QA Wolf.

<Info>
  `axe-core` is already available in the QAW runner. Set `BASE_URL` as an environment variable before running.
</Info>

## Basic page scan

Scans the full page after load, dismisses common UI interrupts (cookie banners, notification bars), and logs any violations found.
