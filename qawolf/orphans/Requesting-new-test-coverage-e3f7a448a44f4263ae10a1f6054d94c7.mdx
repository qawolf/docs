---
title: "Requesting new test coverage"
description: "As you ship new features, you’ll want to add automated tests to your test suite. You can request additional coverage in one of three ways:"
---


### 1. File a coverage request through the QA Wolf application
<Steps>
<Step>
Log into the QA Wolf Application
</Step>
<Step>
Select “Coverage requests” from the left-side menu

<Frame>
<img src="/images/qa-wolf-docs/image-7.png"/>
</Frame>
</Step>
<Step>
Click the “Request coverage” button
</Step>
<Step>
**Fill in the Name and Requirements fields**

Be as clear and descriptive as you can. Links to videos or mock-ups will speed things up. We’ll start working on tests in order of the priority that you assign to them.

<Frame>
<img src="/images/qa-wolf-docs/image-8.png"/>
</Frame>
</Step>
</Steps>

### 2. Send a Slack, Teams, or Discord message

We’ve found that a quick video (Loom, etc.) walking through the new feature, highlighting important functionality and edge cases, and listing some suggested tests is low-effort and highly effective.

### 3. Tag QA Wolf in Jira or Linear

If you’ve connected Jira or Linear to receive bug reports, you can add “QAWolf” to a tag or label field on engineering tickets.

If there are detailed user stories, design files, or screenshots, we can typically outline test cases for you to approve and code them quickly once the feature is in your testing environment.
