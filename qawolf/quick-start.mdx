## Before you begin

import TryForFreeForm from '/snippets/try-for-free-embed.mdx';

<Check>
  Before getting started, make sure the following are set up:

  - **You have access to a QA Wolf workspace.**<br />Create an account below or [Sign in](https://app.qawolf.com/sign-in) to your existing account.

  <TryForFreeForm />

  - **QA Wolf can access the application you want to test.**<br />If your application is behind a firewall or private network, a [**VPN or network allowlist** must be configured](/qawolf/QA-Wolf-s-static-IPv4) so QA Wolf infrastructure can reach it.
</Check>

<Tip>
  Prefer to work from Claude Code, Codex, or another coding agent? [Install the QA Wolf plugin](/qawolf/coding-agents/get-started) to explore your app and create your first flow from that client.
</Tip>

## Step 1: Outline your application

Give the outlining agent a target URL for your application (e.g., staging.wolfcorp.com) and tell it to outline all the workflows.

Read more: [Create a coverage outline →](/qawolf/Map-your-app-s-workflows)

## Step 2: Create a flow

Select a flow and ask the AI to write the test code.

Read more: [Create flows with AI →](/qawolf/Automate-flows-using-AI)

## Step 3: Check in your new test code

Do a code review and check in your changes.

## Step 4: Run your test

Congratulations! You have a test suite.
