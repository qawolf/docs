QA Wolf connects to Azure DevOps using OAuth, so **Third-party application access via OAuth** must be enabled for your organization before QA Wolf can be authorized.

## Requirements

- Access to a QA Wolf workspace
- **Third-party application access via OAuth** enabled in Azure DevOps
- An Azure DevOps project to create bug reports in

## Enable OAuth access in Azure DevOps

Go to `https://dev.azure.com/ORGANIZATION_NAME/_settings/organizationPolicy`, replacing **ORGANIZATION_NAME** with your Azure DevOps organization name, and enable **Third-party application access via OAuth**.

<Frame>
  ![](/images/integrate-your-issue-tracker/image-21.png)
</Frame>

Only an Azure DevOps organization owner can change this setting. If you aren't one, contact your Azure DevOps administrator.

## How to connect QA Wolf to Azure DevOps

<Steps>
  <Step title="Open workspace settings">
    Open the **Workspace name** dropdown above the flows list, click **Workspace settings**, then go to **Integrations**.
  </Step>

  <Step title="Connect Azure DevOps">
    Click **Enable** next to **Azure DevOps**, then click **Connect**.

    <Frame>
      ![](/images/integrate-your-issue-tracker/image-17.png)
    </Frame>
  </Step>

  <Step title="Select the Azure DevOps service">
    <Frame>
      ![](/images/integrate-your-issue-tracker/image-18.png)
    </Frame>
  </Step>

  <Step title="Enter your organization name">
    Enter the Azure DevOps **Organization name** and click **Continue**.

    <Frame>
      ![](/images/integrate-your-issue-tracker/image-19.png)
    </Frame>
  </Step>

  <Step title="Choose the target project">
    Click **Configuration**, then select the target project from the dropdown.

    <Frame>
      ![](/images/integrate-your-issue-tracker/image-20.png)
    </Frame>
  </Step>
</Steps>

To disable the integration, click **Disconnect**.
