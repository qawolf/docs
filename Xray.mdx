## What QA Wolf syncs

For each QA Wolf run, the integration can:

- Create a test execution in Xray.
- Sync automated test results (passed, failed, skipped).
- Link executions to existing Xray test cases.
- Include execution metadata (start/end time, environment).
- Optionally link executions to a test plan.

Results are synced after runs reach Completed status in QA Wolf.

## Limitations

- Cloud-hosted only (Jira Cloud and Xray Cloud).
- Only one Jira/Xray project can be configured per QA Wolf workspace.
- Xray test cases must already exist.
- Test executions are created at the execution level, with no test plan management.
- Custom fields are not supported unless specially configured.

## Requirements

- Jira Cloud instance with [Xray Test Management for Jira](https://marketplace.atlassian.com/apps/1211769/xray-test-management-for-jira) installed
- Xray Cloud API access enabled, which requires a Jira/Xray administrator

## How to set up the integration

<Steps>
  <Step title="Set up Xray and Jira">
    Enable Xray on the Jira project that will receive test executions, and create the Xray test cases QA Wolf will link results to. Tests are not created automatically.
  </Step>

  <Step title="Configure QA Wolf">
    Provide your Xray Client ID and Client Secret, the Jira project key (for example, `QA` or `MOBILE`), and optionally a default test plan to link executions to.
  </Step>

  <Step title="Verify the integration">
    Once QA Wolf enables the integration, run your automated tests. A new Test Execution appears in your Jira project, with results and execution metadata visible in Xray.

    If executions don't appear as expected, or test cases aren't mapping correctly, contact your QA Wolf representative.
  </Step>
</Steps>
