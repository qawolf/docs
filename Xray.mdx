Integrate QA Wolf with [Xray Test Management for Jira](https://marketplace.atlassian.com/apps/1211769/xray-test-management-for-jira) to sync automated test results directly to Jira. QA Wolf configures this integration. You set up Xray and Jira and provide credentials, then verify results once QA Wolf enables it.

## What QA Wolf syncs

For each QA Wolf run, the integration can:

- Create a test execution in Xray.
- Sync automated test results (passed, failed, skipped).
- Link executions to existing Xray test cases.
- Include execution metadata (start/end time, environment).
- Optionally link executions to a test plan.

Results are synced after runs reach Completed status in QA Wolf.

## Limitations

- Cloud-hosted only (Jira Cloud and Xray Cloud).
- Only one Jira/Xray project can be configured per QA Wolf workspace.
- Xray test cases must already exist.
- Test executions are created at the execution level, with no test plan management.
- Custom fields are not supported unless specially configured.

## Requirements

- Jira Cloud instance with Xray installed
- Xray-enabled Jira project to receive test executions
- Xray Cloud API access enabled, which requires a Jira/Xray administrator
- Xray test cases already created, since tests are not created automatically

## What to send QA Wolf

- Xray Client ID
- Xray Client Secret
- Jira project key (for example, `QA` or `MOBILE`)
- Optionally, a default test plan to link executions to

## Verify the integration

<Steps>
  <Step title="Run your tests">
    Run your automated tests in QA Wolf.
  </Step>

  <Step title="Check Jira">
    After the run completes, a new Test Execution appears in your Jira project.
  </Step>

  <Step title="Check Xray">
    Test results and execution metadata are visible in Xray.
  </Step>
</Steps>

If executions don't appear as expected, or test cases aren't mapping correctly, contact your QA Wolf representative.
