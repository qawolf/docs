Integrate QA Wolf with [Zephyr Test Management for Jira](https://marketplace.atlassian.com/apps/1213259/zephyr-test-management-and-automation-for-jira) to sync automated test results directly to Jira. QA Wolf configures this integration. You set up Jira and Zephyr and provide credentials, then verify results once QA Wolf enables it.

## What QA Wolf syncs

For each QA Wolf run, the integration can:

- Create test executions in Zephyr.
- Associate executions with a test cycle.
- Sync automated test results (passed, failed, skipped).
- Include execution metadata (cycle name, environment).

Results are synced after runs reach Completed status in QA Wolf.

## Limitations

- Cloud-hosted only (Jira Cloud with Zephyr Squad or Scale).
- Only one Zephyr-enabled Jira project can be configured per QA Wolf workspace.
- Zephyr test cases must already exist.
- Custom fields are not supported unless specially configured.

## Requirements

- Jira Cloud instance
- Zephyr installed and licensed (Squad or Scale)
- Zephyr-enabled Jira project to receive test executions
- API access enabled via the Atlassian REST API, which requires an Atlassian account administrator
- Zephyr test cases already created, since tests are not created automatically

## What to send QA Wolf

- Jira user email
- Jira API token
- Jira base URL
- Zephyr project key (for example, `QA` or `MOBILE`)
- Optionally, a default test cycle name or naming convention

## Verify the integration

<Steps>
  <Step title="Run your tests">
    Run your automated tests in QA Wolf.
  </Step>

  <Step title="Check Zephyr">
    After the run completes, test executions appear in the configured Zephyr project, grouped under the appropriate test cycle.
  </Step>
</Steps>

If executions don't appear as expected, or test cases aren't mapping correctly, contact your QA Wolf representative.
