{/*
  PREVIEW PAGE — not linked from real navigation beyond the Start tab while
  this branch is open. Deliberately blank apart from the embed, so the page
  shows what the docs shell looks like when this is the only content.

  Approach A: iframe the existing prototype at qaw-prototype.vercel.app.
  Verified embeddable — that host sends no X-Frame-Options and no CSP
  frame-ancestors directive, and docs.qawolf.com's own CSP sets no frame-src.

  allow="clipboard-write" is required: the panel's Copy buttons call
  navigator.clipboard, which is gated in a cross-origin frame without it.

  Height is fixed and set here, because an iframe cannot size itself to its
  content. The two breakpoints match where the prototype's own two-column
  grid collapses to one column (its md: breakpoint, 768px).
*/}
