## Install the QA Wolf MCP <Badge color="green">Recommended</Badge>

<Tabs>
  <Tab title="Codex">
    <Steps>
      <Step title="Install the Codex plugin">
        [Install the QA Wolf plugin for Codex](https://chatgpt.com/plugins/plugin_asdk_app_6aa2be82194c81919e05f3e7c5eedeef?open_in_app). After clicking **Install** you'll be redirected to create an account or sign in.
      </Step>
      <Step title="Sign up for QA Wolf or log in">
        Use your work email when creating a new account. 
      </Step>
      <Step title="Allow access">
        If you're not automatically redirected, return to Codex and click Install again.
      </Step>
      <Step title="Onboard your app">
        Paste this prompt into the chat session for the project you're working on:

        ```text
        Onboard this app to QA Wolf
        ```
      </Step>
    </Steps>
  </Tab>

  <Tab title="Claude Code">
    <Steps>
      <Step title="Install the Claude Code plugin">
        Run these commands

        ```text
        /plugin marketplace add qawolf/agent-plugins
        ```

        ```text
        /plugin install qawolf@qawolf
        ```

        When prompted, choose **Install for you (user scope)**.
      </Step>
      <Step title="Select the QA Wolf MCP server">
        Run this command 

        ```text
        /mcp
        ```

        Then select **plugin:qawolf:qawolf**
      </Step>
      <Step title="Authenticate and approve">
        When you select **Authenticate **a browser window will open with instructions to log in or sign up. 

        - Existing accounts: Sign in and approve the connection.
        - New accounts: Return to your terminal window. Press esc to go back, then choose Authenticate. A browser window will open with a prompt to approve the connection.
      </Step>
      <Step title="Onboard your app">
        Paste this prompt into the chat session for the project you're working on:

        ```text
        Onboard this app to QA Wolf
        ```
      </Step>
    </Steps>
  </Tab>

  <Tab title="Other coding agents">
    Follow the [client-specific setup guide](https://github.com/qawolf/agent-plugins/blob/main/plugins/qawolf/skills/qawolf/references/platforms.md). 
  </Tab>
</Tabs>

## Use the web app

<Steps>
  <Step title="Sign up for QA Wolf">
    [Create your QA Wolf account](https://app.qawolf.com/sign-up?utm_source=help+docs+quick+start+guide). Use your work email when creating a new account.
  </Step>
  <Step title="Onboard your app">
    You'll need to give the agent access to the application you want to test. 

    You can send this prompt with the missing info completed:

    ```text
    Go to {URL of your app} and sign in with username {username} and password {password}
    ```

    Or navigate to your application through the streaming browser.
  </Step>
  <Step title="Automate your test suite">
    If you know what test you want automated, describe it for the agent.

    If you want the agent to build a test suite for you, paste this prompt into the chat:

    ```text
    Explore this application and automate a comprehensive test suite.
    ```
  </Step>
</Steps>
