        ```text
        /plugin install qawolf@qawolf
        ```
      </Step>
      <Step title="Open the QA Wolf MCP server">
        Run this command 

        ```text
        /mcp
        ```

      </Step>

        - New accounts: Return to your terminal window. Press esc to go back, then choose Authenticate. A browser window will open with a prompt to approve the connection.
      </Step>

        Paste this prompt into the chat session for the project you're working on:

        ```text

        ```

  </Tab>

## Use the web app

<Steps>
  <Step title="Sign up for QA Wolf">
    [Create your QA Wolf account](https://app.qawolf.com/sign-up?utm_source=help+docs+quick+start+guide). Use your work email when creating a new account.
  </Step>
  <Step title="Onboard your app">
    You'll need to give the agent access to the application you want to test. 

    You can send this prompt with the missing info completed:

    ```text
    Go to {URL of your app} and sign in with username {username} and password {password}
    ```

    Or navigate to your application through the streaming browser.
  </Step>
  <Step title="Automate your test suite">
    If you know what test you want automated, describe it for the agent.

    If you want the agent to build a test suite for you, paste this prompt into the chat:

    ```text
    Explore this application and automate a comprehensive test suite.
    ```
  </Step>
</Steps>

## Use the CLI

<Steps>
  <Step title="Install the CLI">
    Requires Node.js 20.19 or later, or download a standalone binary from [GitHub Releases](https://github.com/qawolf/cli/releases).

    ```bash
    npm install -g @qawolf/cli
    ```
  </Step>

  <Step title="Sign in">
    Sign in through a browser or with an API key. In CI or an agent sandbox, set `QAWOLF_API_KEY` instead.

    ```bash
    qawolf auth login
    ```

    Read more: [Authenticate the QA Wolf CLI](/local-execution/authenticate).
  </Step>

  <Step title="Pull your flows">
    Find your environment with `qawolf --json environment find`, then pull its flows and install what they need to run.

    ```bash
    qawolf flows pull --env <env>
    qawolf install
    ```

    Read more: [Pull an environment](/local-execution/pull-flows#pull-an-environment) and [Install runtime dependencies](/local-execution/install-dependencies).
  </Step>

  <Step title="Run them">
    ```bash
    qawolf flows run --env <env>
    ```

    Read more: [Run flows locally](/local-execution/run-flows-locally).
  </Step>
</Steps>

The CLI ships a `qawolf-cli` agent skill covering every command, so a coding agent can drive it directly. See the [CLI command reference](/libraries/cli/api-reference/commands) for every command, flag, and exit code, or [Diagnose problems](/local-execution/diagnose-problems) if a step fails.
