Connect QA Wolf to the coding agent you already use, then paste a prompt — the agent explores your app, writes the test, and runs it.

<ConnectAgent />

Using a different agent? Point it at QA Wolf's MCP server at `https://app.qawolf.com/api/mcp`, or follow the [client-specific setup guide](https://github.com/qawolf/agent-plugins/blob/main/plugins/qawolf/skills/qawolf/references/platforms.md). In Claude Code, install from the terminal instead with `/plugin marketplace add qawolf/agent-plugins`.

Once the agent is connected, hand it your whole application rather than a single test:

```text
Onboard this app to QA Wolf
```

**Not using a coding agent?** [Create a QA Wolf account](https://app.qawolf.com/sign-up?utm_source=help+docs+quick+start+guide) and drive the same agent from the browser.

**Already have flows?** Run them on your machine or in CI with the [QA Wolf CLI](/local-execution/get-started).
