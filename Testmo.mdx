Sync QA Wolf automated test results to your Testmo project. QA Wolf configures this integration — you set up Testmo, send the credentials, and verify results once it's enabled.

## What QA Wolf syncs

For each QA Wolf run, the integration can:

- Create a new test run in Testmo.
- Sync automated test results (passed, failed, skipped, errored).
- Include run metadata (title, run link).
- Apply optional tags to all synced runs.

Results are synced after runs reach Completed status in QA Wolf.

## Limitations

- Up to two Testmo projects can be configured per QA Wolf workspace.
- The tags you provide during setup are applied to all synced runs.

<Tip>
  Dynamic tags — different tags for staging and production, or for PR and scheduled runs — require custom configuration by QA Wolf.
</Tip>

## Requirements

- Active Testmo account
- API access enabled, which requires a Testmo **Administrator**

## How to set up the integration

<Steps>
  <Step title="Set up Testmo">
    Define a Testmo project to receive QA Wolf runs, and create any tags you want applied to synced runs.
  </Step>

  <Step title="Configure QA Wolf">
    Provide your Testmo login email, API key, target project (project ID or URL), and any tags to apply to runs.
  </Step>

  <Step title="Verify the integration">
    Once QA Wolf enables the integration, run your automated tests. A new test run appears in your Testmo project with synced results and metadata.

    If runs don't appear as expected, contact your QA Wolf representative.
  </Step>
</Steps>
