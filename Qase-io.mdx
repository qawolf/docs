Sync QA Wolf automated test results to your [Qase.io](https://qase.io/) project. QA Wolf configures this integration — you set up Qase, send the credentials, and verify results once it's enabled.

## What QA Wolf syncs

For each QA Wolf run, the integration can:

- Create a test run in Qase.
- Sync automated test results (passed, failed, skipped, blocked, invalid).
- Include run metadata (title, run/bug link, environment).
- Map results to existing Qase test cases.

Results are synced after runs reach Completed status in QA Wolf.

## Limitations

- Cloud-hosted [Qase.io](https://qase.io/) only.
- Only one Qase project can be configured per QA Wolf workspace.
- Qase test cases must already exist.
- Custom fields are not supported unless specially configured.

## How to set up the integration

<Steps>
  <Step title="Set up Qase">
    - Active Qase.io account
    - Existing Qase project to receive test runs
    - API access enabled, available on paid Qase plans. Tokens are generated at the account level, so this requires a project or account admin
    - Qase test cases already created, since tests are not created automatically
  </Step>

  <Step title="Send QA Wolf your credentials">
    - Qase API token
    - Qase project code (for example, `WEBAPP`, `API`, or `MOBILE`)
    - Optionally, tags or environment values to associate with test runs
  </Step>

  <Step title="Verify the integration">
    Once QA Wolf enables the integration, run your automated tests. A new test run appears in your Qase project, with results and run metadata visible on the mapped test cases.

    If runs don't appear as expected, or test cases aren't mapping correctly, contact your QA Wolf representative.
  </Step>
</Steps>
